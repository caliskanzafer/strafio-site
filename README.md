# strafio-site

Static website for STRAFIO, a data-backed CS2 player POV media brand. Plain HTML and CSS, no build step.
Published with GitHub Pages at https://caliskanzafer.github.io/strafio-site/

- Colors and fonts mirror `config/brand.json` in the private `strafio-engine` repo (Inter, IBM Plex Mono).
- Contact address and social links live in `index.html` and `privacy.html`.
- Preview locally: `python3 -m http.server 8000` and open http://localhost:8000
